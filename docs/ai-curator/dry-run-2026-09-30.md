## How this was run

1. **Export.** `npx wrangler d1 export CATALOG_DB --remote` produced a read-only export of production, 15.3 MB, at 00:29 UTC.
2. **Local database rebuilt.** I stopped the dev server and backed up the local D1 to the scratchpad (`curator/d1-backup/`). Then I deleted the local catalog database, recreated it empty, imported the export with `node:sqlite` (foreign keys off during the import, then 0 violations and a clean integrity check), and applied 0019 locally with `wrangler d1 migrations apply --local`.
3. **Dry run.** A small runner calls `runCuratorNow(env, {mode: 'dry'})` one tick at a time, the same path as the admin's Run now. It uses the test D1 layer (`catalog/test/d1-sqlite.mjs`) on the local D1 file and the real `env.AI` from wrangler's platform proxy. The run was 82 ticks, from 00:32:55 to 00:56:06 UTC.
4. **Checks.** The catalog-table hash was taken before and after. The checks above were computed from `curator_action`, the pre-run snapshot and `merge_candidate`.
5. **Dev server.** I restarted it afterwards, so the plan can be browsed in the local admin (AI curator tab) while it runs.
